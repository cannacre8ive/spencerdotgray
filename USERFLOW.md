# User flow

Open home → scroll or use navigation → scan project index/showcase → read a case study → follow a related project link → browse photography → read About → copy email or open LinkedIn.

Theme toggle switches light/dark and remembers the choice where storage is available. Desktop showcase supports arrows and scroll; mobile stacks the work. Photo reel supports horizontal navigation and mouse dragging. Clipboard failure selects the address for manual copy. No sign-in, form submission, onboarding or database empty state exists.
