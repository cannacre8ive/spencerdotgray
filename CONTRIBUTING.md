# Contributing

Serve locally with `python3 -m http.server 4173`. Keep this dependency-free static site unless a specific feature justifies changing it. Use focused `feature/` or `fix/` branches. Check `git diff --check`, navigation, theme, images and 320px/mobile/desktop layouts. Document material changes in CHANGELOG.md; refresh screenshots and sharing metadata when relevant. Preserve original source and avoid adding secrets. Review factual claims with the portfolio owner before rewriting them.
