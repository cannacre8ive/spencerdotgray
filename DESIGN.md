# Design

Dark base #0a0a0c; secondary #121216; foreground #ecebe8; muted #8f8d99; accent #a99bff. Light theme uses #ececee, #e1e1e5, #121216, #5d5b67 and #5a45de. Bodoni Moda is the display face, Schibsted Grotesk the body face and Spline Sans Mono the utility face. The layout uses a 1320px maximum wrapper and safe-area-aware gutters with a 16px minimum.

Preserve the editorial typography, hairline grids, generous project chapters and original imagery. Desktop uses a pinned six-slide showcase; smaller screens present stacked content. Respect reduced-motion preferences and preserve readable fallback states.
